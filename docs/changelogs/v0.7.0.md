# kmindex 0.7.0

- `kmindex query`: add `-B/--batch-size-base` to size query batches in bases instead of sequences (overrides `--batch-size`)
- `kmindex query2`: multi-index support, `--index` accepts comma-separated index paths
- `kmindex query2`: add `--memory-budget` to limit the memory used by concurrent sub-index queries
- Fix: `--threshold` is now applied to the `matrix` output format, values below the threshold are reported as `NA`
